# Member Side Dashboard API Specifications

This document outlines all required backend REST endpoints, request payloads, headers, and expected response structures for the Member Side Dashboard features (Attendance Slider, Streak Counter, Weekly Activity, Water Tracker, and Today's Exercise Routine).

---

## Base Path
`http://<SERVER_HOST>:<PORT>/api/v1/members`

## Authentication
All requests require a Bearer token in the request header:
`Authorization: Bearer <accessToken>`

---

### 1. Get Member Dashboard Summary
Fetches daily check-in status, streak count, weekly activity boolean array, water intake, body weight stats, and today's assigned exercise list.

* **Endpoint:** `GET /dashboard/summary`
* **Access:** Member only
